# 复刻保真：规格、试样与对照

[English](fidelity-review.en.md)

复刻不能只检查“颜色相近且没溢出”。先约定复刻对象，再核对关键特征是否真正保留下来。

## 1. 定义比较目标

从用户请求判断：是在重建同一份海报，还是将新研究套用参考风格。前者可逐模块对齐原图；后者允许内容与模块数改变，但应保留有依据的视觉特征及适用的编排关系。明确用户指定的尺寸、格式、可编辑范围和允许近似的程度；已有说明足够时直接执行。

先做一张简短特征表，选出真正决定相似度的要素，数量随参考变化：

| 特征与依据 | 保留条件 | 可变化部分 | 不应发生的替换 | 对照位置 |
|---|---|---|---|---|
| 例如：摘要上沿是斜切色带 | 当前参考确有此结构；目标仍有相应分隔功能 | 带宽随页面调整 | 默默改成普通圆角卡片 | 来源页/局部位置 |

标明关键与次要差异，避免花时间复现小阴影却丢失主轮廓。取证含糊时不要宣称“像素级复刻”。

## 2. 容易漏掉的外观信息

| 层次 | 额外记录的具体信息 |
|---|---|
| 整页构图 | 大色块位置和面积、非对称平衡、主图相对大小、标题带高度、内容与空白分布 |
| 字形与排版 | 字族与替代、字面宽度/粗细、大小写、行高、字距、对齐、标题行数和断行位置；中英文不能只按相同字数估算 |
| 内容密度 | 各模块可用面积、正文行数范围、图文占比、图注占用与保留空白；这些是参考观察，不是通用字数上限 |
| 层级与组合 | 背景/前景、相接与重叠、裁切窗口、组件间锚点、相同组件在不同位置的变体 |
| 图表内部 | 轴线、网格、线型、标记、图例、误差条、面板字母和图注的相对大小；样式迁移不改变数据编码 |
| 表面与细节 | 描边粗细、端点、渐变色标和方向、透明度、阴影、纹理尺度；未出现的效果不额外添加 |

扫描件或手机拍摄存在透视、弯曲、反光时，不将这些拍摄失真当成设计。优先获取原 PDF；若校正图像，保留原图并记录校正方式与估计误差。多个参考样本要注明每条规则来自哪一个，不把彼此冲突的风格混成平均值。

## 3. 先验证难点，再完成全页

根据实际疑点做最小试样：特色标题/分隔组件、一处难排的文字、或一张图表即可。没有复杂组件的简单参考不必生成组件库。特殊形状的操作方式见 [shape-reconstruction.md](shape-reconstruction.md)。

试样用真实目标文字检查容量。若不适配，依次处理冗余文案、内部间距、模块面积/组织；保留重要证据和限定条件，记录对参考结构的必要偏离。不要静默横向压扁字体或环形，也不要裁掉溢出的正文。

确认工具能输出所需形状与文本后，再用同一规格完成整页。交付依赖的素材路径保持相对可解析；字体可用性、授权素材来源和外部依赖写入规格。只有字体名或源图路径而没有可获得素材，不构成可复用规格。

## 4. 对照与修正

按以下顺序检查；每轮优先修复影响最大的实际差异：

1. **整页缩略图**：统一画布宽高比和显示尺寸，对照主轮廓、色块面积、焦点、留白与阅读路径。
2. **组件局部**：对照特色形状、组合关系、字形和断行。重建同一内容时可做对齐叠图；迁移新内容时比较角色、比例和结构，不用整图像素差惩罚新文字/新数据。
3. **最终导出**：从实际交付的 PDF 渲染图检查，不以 HTML 预览代替 PDF。核对箭头头部、孔洞、裁切、折面、透明度和字体是否丢失或变形。

将仍存在的差异写成“位置 → 参考特征 → 当前差异 → 原因/下一步”，并标明来源不清、材料缺失、内容适配或工具限制。可修正的关键差异处理完再交付；受缺失素材等条件约束的部分明确说明，不反复盲改，也不输出未经验证的“相似度百分比”。

## 5. 从借鉴仓库吸收什么

本指南独立编写，借鉴其记录方式，不将网站品牌规则直接套到海报：

- [Mastercard 示例](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/mastercard/DESIGN.md)：将圆形裁切、附着元素和连接弧线写为组合组件；这里转化为海报的锚点、层级和使用条件。
- [Clay 示例](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/clay/DESIGN.md)：区分可描述的参数与需要单独素材的插画；这里转化为可重建几何与不可凭 token 还原的素材清单。
- [Stripe 示例](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/stripe/DESIGN.md)：记录渐变背景和表面层次；这里要求观察渐变范围、叠放与实现方式，不照搬其色值或网页布局。
- [贡献指南](https://github.com/VoltAgent/awesome-design-md/blob/main/CONTRIBUTING.md)：修改规格时对照原设计并更新预览；这里转化为试样及最终导出的对照闭环。

这些是该仓库作者的设计分析，不是所涉品牌的官方规范；其当前数值与技术断言也不应未经验证就成为海报规则。
