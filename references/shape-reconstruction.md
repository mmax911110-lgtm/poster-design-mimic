# 异形组件：识别、拆解与重建

[English](shape-reconstruction.en.md)

参考图出现分区环、飘带、波浪边界、斜切面板、徽章、特殊图标或其他定制轮廓时读本页。**先判断是否存在，再决定如何复用。** 这些示例不是默认装饰库。

## 1. 检出与含义判断

按整页和局部两种尺度检查，给候选组件编号 `S1…`，关联所在的内容模块 `M…`：

| 状态 | 记录与动作 |
|---|---|
| 存在 | 保存来源页/局部位置，记录轮廓、组成和用途，进入拆解 |
| 未出现 | 仅在足够清楚的已检查区域内记录“未出现”；不为了美观补上 |
| 无法判断 | 模糊、遮挡或裁切处标未知；不把未知当缺失，也不补造折角或分块 |

先区分组件承担的任务：装饰、标题/摘要分隔、内容容器、关系图、数据图、学科示意或身份标识。一个组件可以兼任多种任务。

- **四分环**：四个类别并列、四步循环和四项百分比是三种不同含义。圆形排列不自动证明有循环；等面积也不证明数据相等。用标签、箭头、图注和原文辨别，无法确认时记录未知。
- **飘带**：判断它承载标题/摘要，还是仅作分隔；折回的尾翼属于背景还是前景；它是否定义了下面正文的起始位置。
- **特殊图标**：判断是可用几何表达的通用符号、领域内有固定含义的符号，还是需原文件的插画/标识。领域符号应核对用户材料，不能按“长得像”替换。

迁移时再次检查目标含义是否匹配。参考图的四区环不能强迫新研究产生第四项贡献；可调整分块数，或改用适合目标关系的布局，并记录原因。统计扇区必须从真实目标数据计算。

## 2. 为组件记录可执行的规格

每种重复组件记录一个基础定义及可见变体，不把不同位置的变体平均成一个样式。复杂组件可附独立 SVG；简单组件用参数和短说明即可。

| 字段 | 要写清什么 |
|---|---|
| 身份与依据 | `S1`、组件族、关联模块、来源页/边界框/局部图、各观察的证据等级 |
| 几何 | 局部 `viewBox`；中心、内外半径、角度、分块数、缝隙、切口、圆角；比例及允许变化范围 |
| 拓扑 | 孔洞、连接/断开、包含、相接、重叠、遮挡；哪些边在前，哪些在后 |
| 外观 | 填充与描边的语义色、线宽、端点、渐变方向/色标、透明度、阴影是否确实存在 |
| 锚点与层级 | 附着在哪个模块/边缘；对齐轴；相对偏移；从后到前的绘制顺序 |
| 文字安全区 | 可容纳标题或标签的区域、内边距、换行与引线规则；哪些区域只能装饰 |
| 内容映射 | 每个分块/标签对应哪个目标内容 ID；箭头方向与关系类型 |
| 实现与降级 | 输出工具、可编辑方式、依赖文件；无法重建的细节和替代方案 |

坐标可在组件局部归一化，但必须保留与整页的位置映射。不要只写“像飘带”“有科技感”或“一个圆环”。轮廓重要时记录路径或可复算参数；图片采样得到的参数仍标为估计。

## 3. 按结构选择实现方式

| 实际对象 | 优先实现 | 核查点 |
|---|---|---|
| 有可复用授权的原始 SVG/PDF 矢量装饰 | 提取路径、分组、变换和裁切，检查依赖后复用 | 不夹带原研究图文或标识；确认文件确含矢量，PDF 扩展名本身不是证明 |
| 分区圆环、花瓣、弧形箭头、定制徽章 | 参数化 SVG `path`；弧线用 `A`，曲线用 `C/Q`，组合基本图形 | 内孔真实透明、分块独立、顺序和方向正确 |
| 飘带、折角、斜切边界、波浪分隔 | SVG 多边形/曲线按前后分层；简单轮廓可用 CSS `clip-path` | 文字独立覆盖在安全区，不能跟随轮廓一起被裁切 |
| 普通圆角框、直线色带、简单切角 | HTML/CSS 或目标编辑器原生形状 | 不用额外复杂路径，也不增加参考中没有的阴影 |
| 原创照片感插画、复杂纹理/三维装饰 | 原始高分辨率素材，或在用户允许风格近似时生成独立图片 | 生成内容不承载精确分块、实验数据、公式或最终正文；说明近似部分 |
| LaTeX / PPTX 等指定交付 | 用 TikZ、原生可编辑形状/文本框，或目标工具支持的 SVG | SVG 可缩放不等于每条路径都能在 PPT 中单独编辑；按编辑需求交付源文件 |

复杂程度不是改用图像生成的唯一依据。需要准确孔洞、分区、连接和标签时优先确定性几何。任意自由轮廓可按原图描摹控制点；先拟合外轮廓和主要转折，再补局部细节。不要把低清抗锯齿噪声描成形状。

无论选择哪种工具，都先做一个最难组件的局部试样，在**实际导出器**中检查；通过后再用于整页。工具不支持的滤镜、蒙版或字体必须显式记录，必要时只栅格化装饰层，保留正文、公式、数据图与标签的清晰度。

## 4. 两种可运行的几何起点

[make_motif.py](../scripts/make_motif.py) 仅用 Python 标准库，输出独立 SVG，无字体或图片依赖。它只提供等分示意环与折叠飘带；其他形状应按观察重建。以下尺寸、颜色均为演示参数，不能当作提取结果。

从技能目录运行；输出目录应已存在。脚本不覆盖已有文件，迭代时使用新的输出文件名。

### 分区环

```bash
python scripts/make_motif.py ring --segments 4 --outer 100 --inner 62 --gap 6 --start -90 --colors '#315C7D' '#3F9090' '#D59B63' '#9A7FA4' --output ring.svg
```

`start` 从朝右的 0° 起算，随 SVG 的向下 y 轴顺时针增长；`gap` 是每条边界总共留出的角度。每区用外弧 → 径向边 → 反向内弧 → 闭合路径，形成真实孔洞，不用背景色圆遮盖。

极坐标位置为 `x = cx + r*cos(θ)`、`y = cy + r*sin(θ)`；第 k 区的起止角为 `start + k*360/n + gap/2` 与 `start + (k+1)*360/n - gap/2`。大弧标志由有效跨度是否大于 180° 决定，内弧反向。整圈没有分缝时应使用两个半圆弧或复合圆路径，不能把起终点相同的一条弧当作完整圆。

将文本放在独立层；每个区块绑定目标 ID。标签放不下时用外置引线或调整布局，不扭曲环来塞字。只有参考图和目标材料确有流程关系时才添加箭头。这个脚本生成等分结构示意，不是统计图工具。

### 折叠飘带

```bash
python scripts/make_motif.py ribbon --width 420 --height 64 --tail 38 --fold 18 --color '#315C7D' --fold-color '#203D52' --output ribbon.svg
```

按后方尾翼 → 暗部折面 → 前方主带绘制；标题或摘要作为独立可编辑文字放到 SVG 标出的安全矩形内。尾翼不能遮挡正文，带高要随真实文字行数检查。脚本示范有折角的飘带；参考若仅有波浪/斜线分隔，应直接重建对应边界，不添加尾翼。

## 5. 组件验收

- 与参考局部按同一宽高比对照：外轮廓、孔洞、分块数量、相接和遮挡是否一致？
- 参数变化后：环是否仍为圆、孔洞是否透明、缝隙是否均匀、飘带折面是否仍接得上？
- 文字是否处于安全区；是否有被遮挡或错误依附的标签/引线？
- 图形表达的关系是否与目标内容图一致，尤其是循环、方向、占比和并列关系？
- 最终 PDF 中的箭头、蒙版、透明度、线宽与字体是否与源文件一致？可编辑要求是否实际满足？

几何定义参考 [W3C SVG Paths](https://www.w3.org/TR/SVG2/paths.html)。组件的采用条件和外观应来自当前海报，不能从本指南或其他设计系统中补造。
